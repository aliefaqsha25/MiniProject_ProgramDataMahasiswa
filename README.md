# Mini Project: Program Data Mahasiswa

Program Java buat masukin sama nampilin data mahasiswa 

## Nama object
1. Alip
2. Kodap
3. Joko
4. Wowo
5. Mahasiswa Tambahan

Pengguna memasukkan NIM dan nilai setiap mahasiswa. Nilai minimal 60 dinyatakan **LULUS**; nilai di bawah 60 dinyatakan **TIDAK LULUS**.


## Materi Java yang digunakan
- **Variable dan data type:** `nama`, `nim`, `nilai`, `int`, `String`, `double`.
- **Scanner:** membaca NIM dan nilai dari input pengguna.
- **If/else:** validasi nilai dan penentuan status kelulusan.
- **Loop:** `for` untuk memproses semua mahasiswa dan `while` untuk validasi nilai.
- **Class:** `Mahasiswa` dan `Main`.
- **Object:** lima objek dibuat dengan `new Mahasiswa(...)`.
- **Method:** constructor, `tampilkanData()`, `cekKelulusan()`, dan `main()`.

## Aturan nilai
Nilai harus berada di rentang 0 sampai 100. Nilai 60 atau lebih dinyatakan lulus.

## Catatan
Proyek buat mata kuliah pemro berorientasi Object
